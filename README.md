# Gemelo digital del clima y la calidad del aire

Página interactiva del Gemelo 2 (Valle de Aburrá, datos SIATA 2017): mapa de calor por zonas sobre el mapa de calles, explorador de zonas con vistas enlazadas, pronóstico, alertas y optimizador de contingencia con OR-Tools.

Funciona sin servidor: `index.html` más la carpeta `vendor/` (Plotly y Apache ECharts). Solo las tipografías y los mapas base necesitan red.

Proyecto académico de Modelos y Simulación, I.U. Pascual Bravo.
