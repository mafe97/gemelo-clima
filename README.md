# Gemelo digital del clima y la calidad del aire

Página interactiva del Gemelo 2 (Valle de Aburrá, datos SIATA 2017): mapa de calor por zonas, pronóstico, alertas y optimizador de contingencia con OR-Tools.

Es un solo archivo HTML (`index.html`) que funciona sin servidor; solo las tipografías necesitan red.

Proyecto académico de Modelos y Simulación, I.U. Pascual Bravo.
