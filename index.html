Mapa de calor por zonas

IDW · relieve y calles

Si el mapa de OpenStreetMap sale vacío o con el aviso «Access blocked», es porque sus servidores pueden rechazar páginas abiertas como archivo local (sin encabezado Referer). En GitHub Pages o con un servidor local (python -m http.server) carga bien; si no, usa el mapa gris.

Pasa el puntero sobre el valle para leer el valor interpolado.

Municipios: MGN-DANE 2018 recortado y simplificado (≈60 m), reproyectado de EPSG:3116 a longitud/latitud. Valores = climatología horaria por estación (laboral, sábado, domingo o festivo) interpolada con IDW de potencia 2 en una malla de 0,3 km. Mapa base: Esri World Light/Dark Gray Canvas (Esri, HERE, Garmin, © colaboradores de OpenStreetMap) o © colaboradores de OpenStreetMap; sin conexión se ve el croquis sin calles.

Cómo se construyó (QGIS → Python)

QGIS es una aplicación de escritorio; en Python se usa el mismo stack geoespacial (GDAL, GEOS y PROJ) a través de GeoPandas, Shapely y PyProj: reproyección, unión espacial estación → municipio, recorte, simplificación y estadística zonal. El código está en el cuaderno, sección B7, y la versión web la genera codigo/genera_web.py.

Cada estación-día de prueba (8 estaciones, 932 días) se alerta si p ≥ p*. p* = 0,20 se eligió con enero–agosto minimizando el costo (falsa alarma = 1, no avisada = 5); el mínimo marcado en la curva se calcula con estas mismas fechas de prueba, así que es optimista. Clic en la curva para mover el umbral.

Cada celda es un día de septiembre a diciembre de 2017. Clic en un día con rombo para abrir su abanico de pronóstico; clic en cualquier otro día para seleccionar la estación.

Comparación de reglas de alerta

POD = aciertos / episodios; FAR = falsas / alertas; CSI = aciertos / (aciertos + falsas + no avisadas). El costo usa los pesos elegidos arriba; la fila resaltada es la de menor costo.

Curva ROC

Cada punto es un umbral: arriba a la izquierda es mejor. El punto naranja es el umbral actual y el cuadrado, la regla de persistencia (alertar si ayer se superó 37).

Optimizador de contingencia

Google OR-Tools · CP-SAT

Para cada estación o zona se elige un nivel de reducción del tráfico (0, 10, 20 o 30 %) que minimiza los días de excedencia esperados sin pasarse del presupuesto: una mochila de elección múltiple. Con 8 zonas hay 4⁸ = 65.536 planes, así que esta página prueba todos para cualquier presupuesto y los compara con lo que resolvió CP-SAT en el cuaderno.

¿Cada cuánto sincronizar?

horizonte de predictibilidad

Error y ancho de la banda P5–P95 según las horas que lleva el gemelo sin recibir datos. Pasado el horizonte de predictibilidad, el gemelo ya no le gana a la climatología.

Datos: SIATA, PM2.5 horario 2017 (8 estaciones con año completo para el pronóstico; 19 con datos, algunas parciales, para el mapa). Modelo: autorregresión en log(PM2.5) con memoria de 24 h. Todo se calcula en el navegador con Plotly; sin conexión funciona todo menos el mapa base de calles y las tipografías.
